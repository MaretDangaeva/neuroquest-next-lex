# НейроКвест NEXT — Лекс

Интерактивный квест про искусственный интеллект. Содержит шесть уровней, меню, подсказки и возможность продолжить прохождение.

## Обновление 12 ноября 2026

- Сокращены повторяющиеся тексты на стартовом экране, карте, в заданиях и результатах.
- В задании «Собери промпт» схематичная картинка заменена на девять заранее подготовленных визуальных вариантов: три локации и три стиля. Фантастический город переключается между тремя готовыми изображениями с разным освещением.
- Все **игровые** изображения находятся внутри `index.html` в формате JPEG. Папка `assets` не требуется. Официальный логотип школы загружается с сайта «Тетрики»; при недоступности используется встроенный резервный вариант.
- Раздел с учебными симуляциями не требует API-ключа. Изображения **не генерируются заново** при каждом клике — игрок сравнивает подготовленные варианты.

## Запуск

Откройте `index.html` в браузере или разместите файл в корне репозитория с GitHub Pages. Сайт обновляется автоматически через GitHub Actions.
