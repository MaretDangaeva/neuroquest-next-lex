# НейроКвест NEXT — Lex Dark Edition

Интерактивный квест по искусственному интеллекту для школьников.

- Шесть игровых уровней: «ИИ или фото», «Обучи два ИИ», «Что умеет ИИ», «Собери промпт», «Разоблачи ложь ИИ», «Свой AI-помощник».
- Кот Лекс — игровой наставник.
- Тёмный высококонтрастный дизайн, адаптация под компьютер и смартфон.
- Все изображения встроены в `index.html` (включая иллюстрации игровых уровней); внешние файлы с изображениями не нужны.
- Квест запускается без API-ключей и сервера. Генерация изображений и AI-ответы внутри уровней — игровые симуляции.
- Ссылка на курс ИИ: https://tetrika-school.ru/ai_kids

## Запуск

Откройте `index.html` в браузере. Для публикации используется GitHub Pages и GitHub Actions из `.github/workflows/pages.yml`.

## GitHub Pages

Settings → Pages → Build and deployment → Source: **GitHub Actions**.

Если сайт открывает старую версию, выполните жёсткое обновление страницы (⌘+Shift+R на macOS).

> Обложка и игровые иллюстрации уже встроены в файл. Не нужно загружать папку assets.
